
# 📊 Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project is a Sales Dashboard created using Power BI to analyze sales performance across regions, categories, and time.

## 🛠 Tools Used
- Power BI

## 📊 Key Metrics
- Total Sales: 522K+
- Total Quantity: 7K+
- Total Profit: 67K+

## 📈 Dashboard Features
- Sales by Category
- Sales by Sub-Category
- Sales by Region
- Monthly Sales Trend
- Profit Analysis
